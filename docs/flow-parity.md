# Moodboard 配色与流程同步 · 2026-10-18

Figma： https://www.figma.com/design/4yegzIqM4FSfyDMJHhF8Rw/design-challenge?node-id=15-596

现有 25 个原型页面已升级配色，保留节点和原型跳转。颜色：#F5F5F5 背景、白卡片、#242424 主行动、#FF2442 首选与选中强调、#FFF0F2 理解与选中底色。Figma 中文字体 Noto Sans SC；网页优先系统 PingFang SC，无外部字体依赖。

网页将部分原型状态合并为可交互控件或弹窗，不把 25 个状态机械复制成 25 个网址。
