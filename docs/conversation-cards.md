# 小晚对话卡片 · 2026-10-18

- 原创小晚头像与可复用消息头。状态在输入、真实录音、偏好核对、排序、完成选择及打卡之间切换。
- 任务复述按当前候选数与结构化偏好生成；点击关键词可修改或删除，完整编辑表单可调整全部条件。
- 推荐图为 SVG 示意图，不读取位置，不接地图服务。点位编号与同一批推荐结果一致；首选点脉冲支持减少动态效果，图例点击同步选择店铺。
- 出发卡读取用户填写的上一站，否则标示示例起点。内置候选使用明确的示例车程；手动候选的未知时间不估算。价格与笔记数量读取候选数据。
- 内置来源显示“依据 N 篇小红书笔记 · 示例数据”，并保留虚构数据说明；手动候选显示“依据 N 段手动笔记 · 未独立核验”。
- 主按钮全宽、黑底白字、至少 52px；次按钮描边。关键词以中性暖灰高亮，红色用于状态、首选标签、点位和行动星号。
- 保留纯 HTML/CSS/JS，无依赖构建。新增 conversation.js 封装复述、来源与示意图，assets/xiaowan.svg 为原创角色。
