# 小薯角色与交互

参考：用户于 2026-10-18 提供并确认的薯队长截图。此为设计挑战中的矢量演绎，不标注为官方素材。

[Figma 状态与交互](https://www.figma.com/design/4yegzIqM4FSfyDMJHhF8Rw/design-challenge?node-id=22-75)

| 状态 | 触发 | 回退 |
| --- | --- | --- |
| 默认 | 进入打卡页 | 悬停、聚焦或点击 |
| 探头 | 鼠标进入、键盘聚焦 | 离开并失焦 |
| 碰掌 | 点击、Enter、空格、手机点按、正反馈 | 1.4 秒后恢复先前状态，连续点击不叠加 |
| 安慰 | 不太行反馈 | 可碰掌后回到安慰；更改反馈或重新打卡重置 |

网页使用原生 SVG、CSS 和独立 mascot.js，不增加依赖。按钮拥有键盘支持与状态播报；减少动态效果模式使用静态底色和文字反馈。

Figma 默认、悬停、点击状态连接组件原型。反馈与系统减少动态效果在网页实现。
